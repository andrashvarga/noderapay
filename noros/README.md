# Noros Pay

Android-приложение «платёжный терминал» для мерчантов Noros. Создавайте ссылку и QR на оплату, следите за заявками и открывайте диспуты. Работает через Merchant API Noros (`https://rest.noros.org/api/v1`, заголовки `api_key` и `api_secret_key`), оформление в фирменном стиле Noros (индиго, Manrope, пиксельный логотип).

## Что работает
- **QR и ссылка**: сумма (или готовая услуга) → `POST /widget` → платёжная страница Noros, QR, «поделиться». Метод оплаты клиент выбирает на странице.
- **Заявки**: активные и архив с таймером, статусами, отменой и чеком (`GET/DELETE /transaction/{id}`, `PATCH /transaction/{id}/proof`).
- **Диспуты**: создание с чеком (`POST /appeal`), статус, отмена. По оплаченной заявке — только при расхождении суммы.
- Баланс и валюта кабинета (`GET /balance`), уведомления о смене статусов (опрос раз в 30 секунд, без Firebase).

## Ограничения API Noros и как они обойдены
- В API нет списков заявок и диспутов, поэтому приложение запоминает заявки и диспуты, созданные в нём, и опрашивает их по одной. Старые заявки кабинета не подтягиваются.
- В API нет истории событий заявки: «ход заявки» показывает создание и текущую стадию.
- В `POST /widget` нельзя ограничить методы оплаты, поэтому выбор метода у клиента.
- Вывода USDT, тестовых ключей и лимитов методов в API нет — этих разделов в приложении нет.

## Сборка
GitHub Actions (`.github/workflows/noros-apk.yml`): шрифт Manrope скачивается при сборке, APK попадает в релиз `noros-latest`. Локально: JDK 17, Android SDK 35, положить `manrope.ttf` в `app/src/main/assets/fonts/`, `gradle assembleRelease` в папке `noros/`.
Подпись: без секретов `NRP_KEYSTORE_B64`, `NRP_KEYSTORE_PASSWORD`, `NRP_KEY_ALIAS`, `NRP_KEY_PASSWORD` используется отладочный ключ из кэша сборок.
