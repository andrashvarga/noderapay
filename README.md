# Nodera Pay

Android-приложение «банковский терминал» для мерчантов Nodera. Принимайте оплату по QR и ссылке, следите за заявками, открывайте диспуты и выводите баланс в USDT — без интеграции API на своей стороне. Работает через Merchant API Nodera (`/api/v1`).

## Возможности
- **Заявки**: активные, архив, диспуты. Диспут по отправленному, но не подтверждённому платежу — чек обязателен.
- **Выводы**: USDT (TRC-20 / BEP-20), сохранённые кошельки, «вся сумма», история. Закрывает вывод сотрудник Nodera вручную.
- **QR**: сумма (или услуга) → метод из кабинета → создаётся депозит-заявка, QR открывает платёжную страницу. Статус оплаты обновляется на экране.
- **Ссылка на оплату**: сумма, методы галочками или на выбор клиента, «поделиться».
- **Услуги и товары**: готовые суммы («Ремонт ПК — 1000»), карточка для показа клиенту, затем QR или ссылка.
- **Настройки**: ключи (замаскированы, только удалить и ввести новые; хранятся в Android Keystore через EncryptedSharedPreferences), тема светлая/тёмная/системная, язык RU/EN, иконка приложения светлая/тёмная, логотип (наш / без / свой), кнопка поддержки в Telegram @tm_chain.
- Инструкция с анимацией (кнопка «?» вверху справа): слайды свайпом, пауза при удержании.

Без `api_key` и `api_secret_key` приложение показывает только экран подключения.

## Установка
1. Откройте на телефоне страницу [Releases → latest](../../releases/tag/latest) и скачайте `NoderaPay.apk` (или возьмите артефакт последнего запуска Actions).
2. Откройте файл, разрешите установку из этого источника.
3. При первом запуске введите адрес сервера Nodera, `api_key` и `api_secret_key` из раздела «Ключи API» кабинета мерчанта.

Адрес сервера — только `https://…`; обычный `http://` принимается лишь для локальной сети (проверка на своём компьютере).

## Сборка
Сборка идёт в GitHub Actions (`.github/workflows/apk.yml`) при каждом пуше в `main`. Локально: Android Studio или `gradle assembleRelease` (JDK 17, Android SDK 35).
Подпись: без секретов `NP_KEYSTORE_B64`, `NP_KEYSTORE_PASSWORD`, `NP_KEY_ALIAS`, `NP_KEY_PASSWORD` используется отладочный ключ (его хватает для установки). Для публикации в магазин добавьте боевой ключ.

## Что требуется от сервера Nodera
Кроме существующего API нужны методы из PR в репозитории Nodera: `GET /transactions`, `GET/POST /appeal(s)`, `/withdrawal*`, параметр `bankIds` в `POST /widget`. Без них соответствующие разделы вернут ошибку.

## Безопасность
- Ключи не пишутся в логи и не показываются полностью; их можно только удалить.
- Вывод доступен только с боевыми ключами; новый кошелёк может быть на паузе по правилам Nodera.
- Приложение не использует резервное копирование Android.
